# Music-hub

A lightweight, distinctive music-discovery web app designed for GitHub Pages.

## Features
- Home dashboard with quick picks and mood mixes
- Search across songs, artists and genres
- Explore, charts, liked songs, recently played and downloads views
- Queue panel and bottom mini-player
- Create local playlist names from the UI
- Responsive mobile layout
- No build step: plain HTML, CSS and JavaScript

## GitHub Pages
Publish the `main` branch from the repository root in GitHub Pages settings.
